## Reporting a Vulnerability

If you discover a security vulnerability in SolidityCore, please report it by opening a **GitHub Issue**.

### How to report
1. Go to the **Issues** tab of this repository
2. Click **New Issue**
3. Use the **Security / Vulnerability** issue template (if available)
4. Apply the following labels:
   - `security`
   - `vulnerability`

### What to include
- A clear description of the vulnerability
- Steps to reproduce the issue
- Affected versions (if known)
- Potential impact or abuse scenarios

### Response timeline
- An initial response will be provided within **48–72 hours**
- Updates will be posted on the issue until it is resolved

### Handling & disclosure
- If the issue is confirmed, it will be fixed as soon as possible
- The issue may be temporarily limited or moderated if sensitive details are involved
- If declined, a clear explanation will be provided

Thank you for helping improve the security and stability of SolidityCore ❤️
